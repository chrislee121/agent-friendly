# 行业剖面

每个行业列出：典型 agent 任务、推荐接入面、R3 动作、额外红线、评分权重（`score.py --profile` 使用，未列出的维度权重为 1）。

## 电商零售 `commerce`

- **典型任务**：按条件找商品、比价、查库存、加购、下单、查物流、退换货、开发票
- **接入面**：schema.org Product/Offer；UCP 或 ACP；远程 MCP（订单、售后）；App 的系统意图（查物流）
- **R3**：付款、确认收货、提交退款、修改收货地址
- **额外红线**：价格和库存必须以服务端实时值为准，不能信 agent 传来的价格；促销规则不能因为走 agent 通道而不同
- **权重**：D3 1.5，D5 1.5，D6 1.5

## 金融支付 `finance`

- **典型任务**：查余额与账单、分类消费、设置提醒、转账给已有收款人、还款、查理财持仓
- **接入面**：远程 MCP（只读为主）；App 系统意图；开放银行接口（如所在地区有）；AP2 授权书
- **R3**：转账、新增收款人、修改限额、申购赎回、借贷申请
- **额外红线**：新增收款人必须带外确认；agent 通道不得提高任何限额；涉及信贷、保险定价的自动化决策要能解释、能转人工
- **权重**：D4 1.5，D5 1.5，D7 1.5，D8 1.5

## 医疗健康 `health`

- **典型任务**：预约挂号、查报告、用药提醒、记录体征、导出给医生的摘要
- **接入面**：App 系统意图（本地数据优先）；远程 MCP（需用户主动开启云同步）；FHIR 接口（机构系统）
- **R3**：改用药计划、取消手术或检查、对外分享健康数据、紧急联系
- **额外红线**：不提供诊断结论，只呈现记录和来源；健康数据出境和对外分享需单独同意；agent 输出要提示「不构成医疗建议」
- **权重**：D4 1.5，D5 1.5，D7 1.5，D8 2

## 旅行出行 `travel`

- **典型任务**：查航班酒店、比较行程、预订、改签、值机、查行李政策
- **接入面**：远程 MCP；A2A（与旅行社 agent 协作）；UCP（结账）；App 系统意图（登机牌、行程）
- **R3**：付款预订、不可退的改签、取消
- **额外红线**：退改规则和费用在确认界面原文展示；锁位要设超时自动释放
- **权重**：D3 1.5，D5 1.5，D6 1.5

## 内容媒体与文档 `content`

- **典型任务**：搜索文章、总结、引用、订阅、管理阅读列表
- **接入面**：语义 HTML；schema.org Article；Markdown 协商；llms.txt；robots.txt 内容偏好；付费内容可用 x402 或订阅 OAuth
- **R3**：付费订阅、以用户名义发布评论
- **额外红线**：内容偏好声明（是否允许训练、是否允许 AI 实时引用）在 robots.txt、HTTP 头和用户协议中保持一致；引用要可回链
- **权重**：D1 1.5，D2 2，D8 1.5

## SaaS 与协作工具 `saas`

- **典型任务**：建任务、更新状态、查报表、邀请成员、导出数据、配置自动化
- **接入面**：远程 MCP（首选）；OpenAPI + Arazzo；WebMCP（复杂网页编辑器）；AGENTS.md 与 llms.txt（开发者文档）
- **R3**：删除项目、改成员权限、对外分享链接、批量操作、付费升级
- **额外红线**：租户隔离：agent 令牌严格限定在一个工作区；批量操作要有数量上限和预览
- **权重**：D3 1.5，D4 1.5，D6 1.5

## 政务与公共服务 `gov`

- **典型任务**：查办事指南、查进度、预约窗口、填表预审
- **接入面**：语义 HTML 和无障碍（强制）；结构化办事指南；只读 API；国内注意 GB/Z 185 系列互联标准
- **R3**：正式提交申请、缴费、授权调取个人证照
- **额外红线**：正式提交必须由本人实名确认；agent 不得代为人脸核验或签署
- **权重**：D2 1.5，D4 1.5，D8 2

## 教育 `education`

- **典型任务**：查课表、提交作业、查成绩、预约辅导、学习进度汇总
- **接入面**：远程 MCP；LMS 的标准接口（如 LTI）；App 系统意图
- **R3**：提交考试或作业、退课、修改成绩、未成年人数据对外分享
- **额外红线**：未成年人账号默认关闭写操作；考试场景要能整体禁用 agent
- **权重**：D5 1.5，D7 1.5，D8 1.5

## 设备与 IoT、智能家居 `iot`

- **典型任务**：查设备状态、开关、调温、设场景、查能耗、报修
- **接入面**：App 系统意图（首选，近场）；远程 MCP（云控）；Matter 等设备标准
- **R3**：开门锁、关安防、改报警设置、远程启动大功率设备
- **额外红线**：门锁和安防类动作必须本人在场或强认证；断网时有安全的默认状态
- **权重**：D5 2，D6 1.5，D7 1.5

## 企业内部系统 `enterprise`

- **典型任务**：查客户与工单、审批、报销、查库存、生成报表、HR 自助
- **接入面**：内部远程 MCP（经企业身份网关）；OpenAPI + Arazzo；A2A（部门 agent 之间）
- **R3**：审批付款、改合同、改权限、对外发送客户数据、删除记录
- **额外红线**：agent 权限不得超过发起人；审批类动作不能由同一个 agent 发起又批准；接入企业 SSO 和数据防泄漏策略
- **权重**：D4 1.5，D7 1.5，D8 1.5

## 通用 `default`

所有维度权重为 1。不确定行业时使用。
